# Drum maps: preset data (2026-11-17, ticket THE-219)

This note records where the numbers in the five library layouts of `src/audio/drum-maps.json` came from. Other sections of the drum map work (the editor, the file format, hosted instruments and MIDI output) are recorded elsewhere or not yet.

## Preset data

**Status in one line: every number below is unverified.** Nothing was checked against EZdrummer 3, Superior Drummer 3 or a GetGood Drums library, because none of them was installed or opened for this work. Each layout is stored with `"state": "unverified"` and a `source` text that says so, and the panel shows it as "not yet checked". The owner's own exported layouts (Drum map, Export) are the reference: once the owner has a library open and has corrected a map by ear or from the library's own mapping view, that file replaces whatever is guessed here, and a layout becomes `verified` only with a `checked` date and what it was checked against.

### Names

The layouts are named after the libraries they follow, as compatibility labels, by the owner's decision of 2026-11-17 for this ticket (an exception to the repository's rule against brand and product names). The names appear in the preset `name` and `source` in `src/audio/drum-maps.json`, in the tests of these presets, and in this note. There are no logos and no claim of endorsement or affiliation; the panel footer says the names only say which layout a map follows and that TabPlayer is not affiliated with these products or their makers. A test (`src/audio/drum-map.test.ts`) fails if a name appears anywhere else in `src` or `src-tauri/src`. No brand-name guard existed in the repository, so none was changed.

### Layouts shipped

| id | name | what it rests on |
|---|---|---|
| `ezdrummer-3` | Toontrack EZdrummer 3 | three third-party sources |
| `superior-drummer-3` | Toontrack Superior Drummer 3 | four third-party sources |
| `ggd-modern-and-massive` | GetGood Drums Modern & Massive | three sources that agree |
| `ggd-invasion` | GetGood Drums Invasion | a published note chart and a lookup table of the One Kit Wonder libraries, which share the layout |
| `ggd-okw-architects` | GetGood Drums One Kit Wonder: Architects | a published note chart and a lookup table that agree |

The GetGood Drums layout differs per pack, so each pack is its own layout. Not shipped, because only one source or none was found: the other One Kit Wonder packs (a lookup table exists for the Metal pack and it differs from Architects in its toms; no second source was read), Modern & Massive 2, Benny Greb, the Matt Halpern kits and the Halpern and General MIDI mappings those libraries offer.

### Sources read, and their terms

All reads were of public pages in November 2026. Only note numbers were taken, as facts; no file was copied into the repository, and the presets were written afresh in this app's own format. The rows were generated from a table of sounds and then checked against the catalogue of 94 sounds, so each id is listed once.

1. **drum-mapper** (https://github.com/insomnimus/drum-mapper). MIT licence (the repository's licence file was read). Files read: `drums/EzDrummer 3.txt`, `drums/Superior Drummer 3.txt`, `drums/GGD - OKW Architects.txt`, `drums/GGD - OKW Metal.txt` (compared only), `drums/EzDrummer 2.txt` (compared only). Each line is `General MIDI note -> library note`; a General MIDI note is mapped to the one library key nearest to it, so several General MIDI sounds can share a key and techniques are not told apart. The numbers are MIDI note numbers.
2. **Drumverter** (https://drumverter.com). Pages read: `/engines/ezdrummer/`, `/engines/superior-drummer3/`, `/engines/ggd-modernmassive/`, `/engines/ggd-invasion/`, `/engines/ggd-architects/`, and the engine index; five chart pages in all, with no bulk reading. Its `robots.txt` allows these pages (it disallows only `/drum-maps/files/`, which was not touched), and no map file was downloaded. Its terms (https://drumverter.com/terms/) say the data is provided as is and may be wrong, that engine and product names belong to their owners and are used only to say which layout is meant, and nothing about reuse of the charts. Licence status: none stated; only numbers were taken. The charts are machine-generated and list every key an engine answers to, including duplicates, so they show what a key can do and not which key is the main one.
3. **Whack Studio guides** (https://whackstudio.com/how-to-use-drum-midi-in-ezdrummer-3/ and https://whackstudio.com/how-to-use-drum-midi-in-superior-drummer-3/). Licence status: none stated; only numbers were taken. The EZdrummer 3 guide records what each General MIDI key played in the library's own mapping layout view (kick 36, snare 38, closed hi-hat 42, open hi-hat 46 as open level 2 of 6, toms 43, 45 and 47, crash key 49 playing crash 2, ride 51 bow tip, key 52 playing the ride edge, ride bell 53, crash key 57 playing crash 3, key 50 playing crash 2 muted, and key 55 playing crash 1, which the guide counts as wrong). The Superior Drummer 3 guide quotes the maker's manual for a few keys (kick on 35 as the plain hit and 36 as the open kick, snare 38, closed hi-hat tip 42, open hi-hat edge 2 on 46, toms 43, 45 and 47) and says cymbals from 49 to 57 depend on the kit. This is a second-hand quotation of vendor documentation, not the documentation itself.
4. **studio-one-drum-maps** (https://github.com/chad-ramos/studio-one-drum-maps). No licence file, so numbers only. Files read: `Superior Drummer 3.pitchlist` and `GGD Modern and Massive.pitchlist`. They are XML lists in which each pitch equals the number in its name.
5. **A public gist** (https://gist.github.com/keeprocking/a2aa70a16dc7185d38ffd3e792fdcc27), "GGD Modern & Massive note names for Reaper, Halpern preset". No licence stated; numbers only. A Reaper note-name file, one number and name per line.
6. **Toontrack forum thread** "Difference in mapping EZ drummer and General MIDI?" (https://www.toontrack.com/forums/topic/difference-in-mapping-ez-drummer-and-general-midi/). A staff reply says EZdrummer 2 follows a General MIDI Extended map and points to the library's own layout view; it gives no numbers.

Read and not used: the GetGood Drums support article on Modern & Massive 2 mapping (https://support.ggd.co/hc/en-us/articles/31476793134743) returned HTTP 403, and its search summary only says factory mapping configurations exist, with no table. Some pages (Scribd) need an account and were not opened. A converter project for GetGood Drums presets (JPplayground/MidiNoteNameGen, GPL-3.0) was looked at and not used, because it holds no note listing in its readme and its data would have meant reading a licensed work.

**Vendor documentation:** none was readable. No row is vendor-documented. Rows that the second-hand quotation of the Superior Drummer 3 manual covers (kick, snare 38, closed hi-hat 42, open hi-hat 46, the three tom keys) are the closest.

### Octave convention

Every number used is a MIDI note number as the source prints it. No source used here gives only names, so no octave conversion was applied and there was no 12-semitone step to get wrong. Drumverter prints names under two conventions beside each number (kick 36 is C2 with C-1 = 0, and C1 with C-2 = 0); only its number column was used. The app's own note column calls 60 C4.

### Rule for filling rows

A key is used only when at least one source supports it for that sound. Where sources disagree, the best-supported key is the row and the others are its `candidates`, which the editor shows as one-click tries. A technique the library has no separate key for points at the piece's plain key only when a hit on the piece is clearly better than silence (a ride's middle, rim shot, side stick and half-open hi-hat on a snare or hi-hat). A choke with no mute or choke key is silent, because striking the cymbal again is the opposite of a choke. A library that names a muted hit ("Crash 2 (Mute)", "Ride (Mute)") has it used for the choke; that is the library's name for it, not a documented choke. Percussion a library does not have is silent. The six General MIDI toms (high, high-mid, low-mid, low, high floor and low floor) go to the library's toms from the highest to the highest, and the extra ones share the lowest rack tom (see below). The second ids of a sound (side stick 2, ride edge 2, ride middle 2, ride bell 2, ride choke 2, the tambourine and shaker variants, the two clash cymbals) follow their first.

### EZdrummer 3

The sources agree on kick 36, snare 38, side stick 37, ride middle 51 and ride bell 53, and on 46 as an open hi-hat key.

- **Closed hi-hat:** 42 (the Whack Studio layout check and Drumverter's closed tip), where the lookup table gives 22 (closed edge). Candidates 22 and 61.
- **Pedal hi-hat:** 21 (the lookup table and Drumverter), where Drumverter also lists 44 and 10. Candidates 44 and 10.
- **Open hi-hat:** 46 (Whack Studio, Drumverter), where the lookup table gives 24. Candidates 24, 25, 26. **Half-open:** 24, the lowest open level by its name; no source says which key is half-open.
- **Crashes:** 49 and 57 (Whack Studio and Drumverter), where the lookup table puts them on 86 and 49. Candidates 86 for the high crash, and 49 for the medium one. Chokes use 50 and 58, the muted crash keys.
- **Splash:** 55 (Drumverter), while Whack Studio's check found the library playing a crash on that key. Candidate 86.
- **China:** the library has no china in any source; the lookup table sends it to crash 1 (86), which is used. Its choke is silent.
- **Ride edge:** 52 (Whack Studio, Drumverter) with candidates 59 and 115; the choke is 54, the muted ride.
- **Rim shot:** 40 (Drumverter). **Electric snare:** the plain snare 38 (candidate 40, which is the rim shot key).
- **Toms:** 50 to 48, 48 to 47, 47 to 45, 45 to 45, 43 to 43, 41 to 41. The library has three rack toms and two floor toms; the lookup table makes this choice. Key 50 is a muted crash in this library, so the high tom cannot stay where it is. Whack Studio's check shows 45 and 47 as rack toms 3 and 2, kept as candidates.
- **Kick 35:** 36, with candidate 35 (Drumverter lists 34, 35 and 36 as kick).
- **Percussion:** clap 1, shaker 2, tambourine 3 (Drumverter; the lookup table agrees for the tambourine). Everything else, including cowbells, is silent.

### Superior Drummer 3

- **Kick:** the plain hit 35 and the open kick 36, as the second-hand quotation of the manual says; the lookup table sends 35 to 36. Candidates 36, 35 and 34.
- **Closed hi-hat:** 42 (manual quotation, Drumverter, Studio One list). The lookup table gives 22; Drumverter also lists 61 and 22. Candidates 61 and 22. **Open:** 46. **Half-open:** 24 (open edge 1), no source says. **Pedal:** 44 (candidates 21, 10).
- **Ride:** bow tip 51 (Drumverter, Studio One list), where the lookup table gives 29 (bow shank). Candidates 29 and 113. Edge 59 (candidate 115), bell 53 (candidates 30, 114), choke 118 (the muted ride).
- **Crashes:** 49 (crash 2) and 57 (crash 4), chokes 50 and 58, as the Studio One list names them. The medium crash also has candidates 49 and 55.
- **China:** 52 (the Studio One list calls it cymbal 5, Drumverter calls it china 1), choke 54.
- **Splash:** the library has none in any source; the lookup table sends it to 52, which is used (candidate 55, a crash). The choke is silent.
- **Rim shot:** 40; **side stick:** 37; **electric snare:** 38 with candidate 40.
- **Toms:** as for EZdrummer 3.
- **Silent:** hand clap, tambourine, shaker, cowbells and the rest of the percussion (Drumverter lists one unnamed "Percussion" key, 65, which was left alone).

### GetGood Drums Modern & Massive

The gist, the Studio One list and Drumverter agree on every number used.

- **Kick** 24, **snare** 26, **side stick** 30, **rim shot** and **electric snare** on the snare hit 26.
- **Hi-hat:** closed 47 (candidates 45 tight and 48 loose), pedal 43 (candidate 44, the pedal splash), half-open 53 (open 0) and open 54 (open 1), by the order of their names. No source says which open level is which General MIDI sound. Candidates 53, 56, 58.
- **Toms:** one rack tom (33) and two floor toms (37 and 39). The four General MIDI rack toms go to 33, the high floor tom to 37 (Drumverter also lists 35 as floor tom 1, candidate) and the low floor tom to 39.
- **Ride:** tip 72, edge ("hit" in the gist, "crash" in the Studio One list) 73, bell 74; no ride mute, so the chokes are silent.
- **Crashes:** left 62 and right 67, chokes 64 and 69. **China** 76, choke 77. **Splash** 83, choke 82.
- **Silent:** hand clap and all other percussion.

### GetGood Drums Invasion

Drumverter lists the default mapping; the lookup table for the One Kit Wonder libraries (same layout) agrees for kick, snare, side stick, pedal, open 1, the crash 1 and 2 keys, ride, ride bell, china and splash.

- **Kick** 24 (candidates 22 alt and 23 left), **snare** 26, **side stick** 30.
- **Closed hi-hat:** 43 (closed tip) where the lookup table uses 44 (closed edge). Candidates 44, 41, 42. **Open:** 45 (open 1, the lookup table's choice for open), candidates 46 and 47. **Half-open:** 45 as well, no separate key is documented. **Pedal** 48.
- **Toms:** six, from the highest to the highest: 33, 34, 35 (rack) and 36, 37, 38 (floor).
- **Ride** 62, **edge** 63, **bell** 61, **choke** silent (the library lists no ride mute; the One Kit Wonder Architects list has 64, kept as a candidate).
- **Crashes:** 52 and 54, chokes 53 and 55. **China** 65 (candidate 67), choke 66. **Splash** 73 (candidate 75), choke 74.
- **Silent:** hand clap and all other percussion; the library's aux hat, stack and bell keys have no standard sound to carry.

### Rows nobody documents

No source says which key plays a half-open hi-hat in any of these libraries; the half-open rows are a choice among the open keys by name. No source covers the electric snare, the reverse cymbal (silent in all five) or the two clash cymbals (115 and 116), which follow the high crash key. The choke keys of the Toontrack libraries are muted hits named by the sources, not documented chokes. No source says what the China choke does in EZdrummer 3, so it is silent. The splash of Superior Drummer 3 is a stand-in. The general percussion in all five layouts is silent except the clap, shaker and tambourine of EZdrummer 3.

### Limits

- Nothing was checked against any library.
- Drumverter, Whack Studio, the Studio One list and the gist are third-party and may be wrong or describe a different edition of a library or a different kit; Whack Studio says itself that cymbal keys depend on the kit.
- Superior Drummer 3 and EZdrummer 3 can be remapped by their users and by the library's own presets, so a different layout may be in use on any machine.
- GetGood Drums layouts differ per pack and per mapping, and only the default mappings of the three packs above were read.
- The first-hand source for all of this is the library's own mapping view; exporting a map from it into this app's file format is the way to replace these rows.
