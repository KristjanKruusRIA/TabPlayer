# Sound rig Lows: short-window layout, busy fieldsets, drum kit

## Behavior

- **Short windows (height 700 or less).** The head no longer changes height with the width or the track. Every group in it (tracks, sources, presets, lock, kit) is 30 px tall, so a row is as tall whichever groups share it. The sound lock was a column (checkbox above its text, 38 px); it is a row. The drum kit moved to the end of the head, and a pitched track renders the same slot empty (`rig-drum-kit-reserve`, hidden, `aria-hidden`), so changing to a drum track moves nothing. The stage title row (name, place, model strip, actions) never wraps: the model strip scrolls first, the actions tighten. The main area's bottom padding is the same either side of 1100, where the sound browser appears.
- **`SoundPanel` busy.** Its four `fieldset disabled={busy}` are `BusyFieldset`: `aria-disabled`, refusing clicks, presses, typing, pastes and changes, never the `disabled` attribute. The control that holds focus keeps it when busy starts, and a busy-time click lands nowhere and leaves focus where it was.
- **Rig drum kit.** New `src/rig/RigDrumKit.tsx` (the inspector keeps `src/audio/DrumKitPicker.tsx`, unchanged). The select has a visible "Drum kit" label. The kit table is a popover opened by a `?` button (`aria-expanded`, `aria-controls`), absolutely placed under that button inside the kit's box with right edges aligned. It closes on Escape wherever focus is (including after a click on its text, which leaves focus on the page), on a press outside it, when focus moves outside it, and on the button again. Escape returns focus to the button. Sound behaviour is unchanged: the select is still `editing.setDrumKit`, one undoable edit, and stays focusable while busy (`busySelect`).

## Limits

- Not fixed: at 701 tall the full layout (larger chain, drawn sources) replaces the compact one, so the art is 78 px shorter (pedal, cabinet) to 112 px shorter (amp) at 1280x720 than at 1280x700. The tall layout's decoration costs more than the compact one at every height; removing the step means redesigning it.
- The head is two rows (73 px) from 960 to 1500 wide where a guitar track used to get one row (47 px) from 1300; that height is what keeps it from changing with the track.
- The harness is an approximation of the shell, not the running Tauri window (the shell chrome height is fixed at 130 px). No desktop driver run.
- `rig.css` line numbers in the brief had moved; the jumps were found by measurement, not by the cited lines. Heights above 700 were measured only at 1440x900.
