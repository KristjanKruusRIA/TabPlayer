# GP8 Backing Waveform Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver P15 real waveform/grid/zoom and reversible occurrence-aware sync-point editing in the existing Backing dock.

**Architecture:** One owner/revision/source-bound read query captures encoded bytes cheaply, serializes full decode on one waveform work gate outside existing locks, and returns bounded true peaks. Pure TypeScript projects current performed timing/backing maps; the isolated view previews gestures locally and commits one existing setBacking. Root integrates shared seams after independent producer review.

**Tech Stack:** Existing Rust1.88/Tauri2, Symphonia0.6.1, SHA-256/base64, React19/TypeScript, alphaTab1.8.4, Vitest; no new dependencies.

**Spec:** [2026-10-15-gp8-backing-waveform-design.md](../specs/2026-10-15-gp8-backing-waveform-design.md). Status: reviewed for implementation; checkboxes track accepted tasks. User standing execution method is parallel work in this chat plus independent review; root reviews/freezes both artifacts before implementation, without a new approval question.

## Global Constraints

- Preserve native audio clock, immutable source/history, explicit document/activation ownership and output-device-independent waveform reading.
- No new dependency or global asset/job/cache framework. `AudioService`, device and renderer remain unchanged.
- P16 tempo generation/brackets, pitch/filter/codec/recording/trim/transport/waveform-to-score actions remain outside this slice.
- buckets integer1–8192; UI requests8192; new query-only MAX_WAVEFORM_AUDIO_BYTES=512*1024*1024 raw encoded-audio-container bytes after base64 decoding. Predecode text cap is4*ceil(limit/3), with padding-derived binary length check, then actual bytes.len()<=limit. This is not an incumbent universal backing import cap or a decoded-PCM heap bound.
- Full incumbent decode is not streaming/cancellable. One waveform work gate, no expensive work under audio/workspace locks; owner/revision/source recheck after wait, before decode and before response.
- Actual GenAI reference/provenance paths and PNG hash are pinned in spec. Preserve existing adaptive dock/right-Inspector geometry, numeric anchor controls and gain units; generated incidental bar/time relationships are not data.
- Root alone owns Cargo slot, shared files, build/app/CDP/desktop acceptance and Git. No old physical/Long captures, installer execution, cleanup or private-source commits.

## Review Focus

1. Revision/source changes while a decode waits or runs must never display old peaks or mutate/hold the current workspace; pinned by Tasks4/5.
2. Nonzero offset and an intra-bar tempo change must place/drag the same real point as Rust BackingMap, not a whole-bar approximation; pinned by Tasks2/3.
3. Opposite-phase stereo or a one-frame transient must remain visible; no averaged/sample-only fake waveform; pinned by Task2.
4. Original embedded source must display before conversion with zero staging/history, reject a different base/digest, and work without a device; pinned by Tasks4/6/7.
5. The gesture's own workspace lease/busy update must not self-cancel or produce multiple edits; external invalidation/Escape/blur must cancel and release once; pinned by Tasks5/6.
