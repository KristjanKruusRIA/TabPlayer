# GP-style layout: track dock, edition palette, toolbar position display (2026-11-06)

Branch `feature/gp-layout`. The goal was a layout that Guitar Pro 8 users recognise, in TabPlayer's own visual style. The references were:
- the craft-anything rebuild of GP8, including its `app/UI-NOTES.md`;
- 14 full-resolution GP8 view captures taken with computer use and kept in the craft project under `capture/views/`.

No Guitar Pro icons, artwork or text assets were copied.

## What changed

- **Track dock (Overview tab).** Each track row has:
  - a grey track number;
  - a strip in the track colour, with a soft track-colour tint on bars that hold music;
  - Mute and Solo toggles;
  - Volume and Pan sliders. Double-clicking the pan slider centres it.

  The controls dispatch the existing mixer commands, and playback ticks re-render only the controls, not the grid.
- **Toolbar.** The transport moved to the top, with First, Previous, Next and Last bar buttons. The position display (an LCD) shows:
  - the selected track's number and name, with a strip in its colour;
  - the bar, as "Bar n of N";
  - elapsed and total time;
  - the time signature and tempo;
  - a progress line along the bottom edge.

  More playback opens downward.
- **Edition palette.** The editing toolbar can show as a vertical two-column palette left of the score. A View menu checkbox, "Edition palette", toggles it; when hidden, the toolbar returns to the inspector. The palette scrolls when the window is short, as GP's does.
- All new text is in `src/i18n` (en, et, de).

## Position display follow-up

The position display now acts on what it shows, as GP's does:
- **Track name:** a menu of every track; picking one makes it current, through the same selection path as the command palette's Go to track.
- **Bar number:** opens a small Go to bar form. Go moves both the cursor and playback to that bar. Escape or a click outside closes it and returns focus to the bar number.
- **Time signature and tempo:** each opens the inspector's Measure scope for the shown bar and focuses Measure & notation, opening any collapsed section around it.
- **Bar-completion mark:**
  - a green ✓ when every voice that holds beats fills the bar;
  - an amber ! when the bar is empty or a voice is too short;
  - a red ! when a voice is too long.

  Its name says which ("Voice 2 is too short"). The logic is in `src/editor/bar-completion.ts`.
- While busy, these links follow `useBusyGuard`: they stay focusable and ignore activation.

## Dock and palette follow-up

- **Dock eye:** each row's eye shows or hides that track in the score, as Displayed tracks does; picking one switches it to "Chosen tracks". This is view state, not an undoable edit. The last shown track's eye cannot close.
- **Master row:** under the tracks, with the master level and balance aligned to the Vol./Pan columns. Each drag is one master change, through the same `useMasterChange` path as the mixer's master strip, now shared from `MasterPanel.tsx`.
- **Resizing the dock:** drag its top edge, or focus it and use the arrow keys, Home or End. Double-click or Escape returns it to the automatic height. The height stays between 96 px and 460 px, and always leaves the score at least 200 px. It is kept for the session only.
- **Palette:**
  - Voices 1–4 come first, with a colour stripe each. Voices the bar does not have are disabled.
  - Time signature and tempo buttons open the measure settings.
  - ppp–fff set the cursor note's dynamic through the inspector's edit. Choosing the current dynamic records nothing.
