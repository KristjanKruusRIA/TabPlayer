# Pitched trill sounding-transposition correction

Date: 2026-10-16. This is the next bounded, non-UI GP8 parity tranche, prepared while root completes P17/P18 delivery. All scoped parity changes are authorized; no additional approval gate is introduced. Implementation starts after root releases the current delivery. Graph tools were unavailable; preparation used exact source reads and `.analysis/parity/next-interchange-boundary-seams.md`.

## Outcome and boundary

A non-stringed pitched trill must retain its authored interval when staff sounding transposition changes. Written base 60 / alternate 62 with sounding offset +12 must produce 48/50; offset −12 must produce 72/74. Canonical written music stays 60/62. Display transposition changes neither sound nor canonical storage.

Production changes are limited to `src/interchange/pitched.ts` `preparePitchedGpScore(score:model.Score,settings:Settings):model.Score` and `src/audio/plan.ts` `prepareMidiScore(score:model.Score):model.Score`, including the necessary import. Existing signatures and callers remain unchanged. Stringed and percussion staves are untouched. No new UI, dependency, schema, IPC, renderer, transport or native DSP change is needed; the new-UI GenAI requirement does not apply.

The supported acceptance domain has normalized base and active alternate pitches within MIDI 0–127. Include valid boundary 0/2, but do not invent a broad out-of-range/clamping policy. Unrepresentable combinations remain outside this tranche's claims.

## Existing defect and selected approach

`preparePitchedGpScore` already clones with independent dynamics, note relationships and detached backing bytes, folds the base sounding pitch into `octave`/`tone`, and sets the eligible detached staff's sounding offset to 0. It currently leaves `trillValue` absolute. Pinned alphaTab 1.8.4 applies staff sounding offset to the base MIDI key but uses unchanged `trillValue` for alternate attacks. The existing assertions in `src/interchange/pitched.test.ts` and `src/harmony/transpose.test.ts` honestly characterize the resulting wrong interval.

Extend that existing detached normalization to fold an active pitched trill's alternate by the same sounding offset as its base. Normalize both from the original source values, then zero the detached staff's sounding offset. Preserve `displayTranspositionPitch`. Repeated preparation therefore does not apply another shift; an already normalized score retains the existing no-normalization return path.

Reuse `preparePitchedGpScore` inside `prepareMidiScore` before the existing negative-duration tremolo normalization. The existing playback-plan and SMF callers already call `prepareMidiScore`; GP export already calls `preparePitchedGpScore`. This supplies one pitch normalization rule for all three routes. Keep tremolo correction and its link-preserving clone unchanged apart from composing it with the prepared score. Full-score and source-lane generation must receive coherent pitches; lane-only chord-carrier sentinels are assigned later and must not be renormalized.

A separate alternate-only MIDI patch would duplicate pitch policy and make double subtraction possible. Mutating canonical pitches would change authored music/history. Neither is needed.

## Literal artifact acceptance

Create one small independently authored fixture: one 4/4 bar at 120 BPM, a non-stringed whole-note base 60, alternate 62, Sixteenth trill, dynamics 3. Assign independent note dynamics after model finishing where necessary. Expected values are literal musical arithmetic, never generated by alphaTab or the production preparation functions:

| Sounding offset | Alternating keys | Detached base / alternate / sounding offset | GPIF Trill |
|---|---|---|---|
| +12 |48,50|48 /50 /0|`<Trill>50</Trill>`|
| −12 |72,74|72 /74 /0|`<Trill>74</Trill>`|
| 0 |60,62|60 /62 /0|`<Trill>62</Trill>`|

Each case has exactly 16 attacks at ticks 0,240,…,3600; paired releases 240,480,…,3840; every attack velocity 63; PPQ 960 and duration 3840 ticks. A display offset +7 changes none of these values. The +12 valid low-boundary fixture written 12 / alternate 14 produces 0/2. Harmony transpose +1 at sounding offset +12 keeps canonical written 61 / alternate 63 while emitting 49/51.

One new `src/interchange/pitched-trill-oracle.test.ts` owns the cross-route fixture and a small independent Standard MIDI byte decoder. Check actual `exportMidi` bytes, `buildPlaybackPlan` and `buildPlaybackPlanFromJson` against the same literal event table and source-note address. Do not use `src/audio/plan.test.ts`'s `agree()` comparison to the same public generator as the decisive trill oracle.

Export through `exportGpInterchange`, unzip with existing `fflate`, parse GPIF with `DOMParser`, and assert exact Trill text 50/74 plus the expected detached main pitch and valid note references. Reopening and checking MIDI is complementary evidence; an importer roundtrip alone cannot establish the XML contract. Raw unprepared public generation may remain a narrowly labeled legacy negative control 48/62 or 72/62, never the corrected expectation.

Before production edits, run the new literal oracle and record its failure on the wrong alternate pitch. Only then update the owned bad-interval characterizations to the corrected prepared/exported values. Keep a single clear negative-control demonstration: that baseline RED is sufficient if it isolates the wrong alternate. If it does not, temporarily bypass alternate normalization in the producer-owned source, show the literal assertion fails, restore exact bytes and rerun GREEN. No mutation framework or four separate harnesses are needed.

## Preservation and verification

Repeated `preparePitchedGpScore` and `prepareMidiScore` must preserve normalized values rather than subtract twice. Retain the neutral identity return where neither pitched normalization nor tremolo correction applies. Test normalization together with the incumbent negative-duration tremolo path, including the duration/id/link assertions.

Retain mixed-staff coverage: different pitched offsets normalize independently; stringed frets/tuning/sounding offsets and percussion articulations/offsets stay exact. Add a pitched chord containing a trill and a nontrill neighbor, so lane isolation retains the real neighbor and cannot emit its temporary carrier pitch or alternate. Retain ordinary no-trill sounding/display-pitch assertions. Existing ties/slurs, independent velocities, detached backing and archive siblings remain protected by the focused incumbent tests.

Use the focused oracle/incumbent Vitest files and TypeScript check, then a fresh independent source/oracle review and root focused verification. Do not automatically rerun the unrelated 2647/617 whole suites, Cargo, desktop builds or actual app. Broaden checks only for a specific new failure or risk.

The final versioned validation report records exact source/test/artifact hashes, failing-before/passing-after evidence, the independent review, preservation limits and commands actually executed. This establishes bounded source behavior and serialized MIDI/GP artifacts. It establishes no physical audio/listening, original-GP8 runtime, platform, installer or shipping equivalence.
