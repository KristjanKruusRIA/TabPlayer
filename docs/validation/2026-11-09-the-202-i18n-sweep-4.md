## 6. Limits
This sweep is complete for the files above and the strings they render through `t(...)`. Not covered, on purpose or not yet:
- **Batch convert report details.** The Details column text (`3 tracks, 4 bars. Saved as …`, `Cancelled before this file.`, losses, skip reasons and file errors) is built in `src/batch/convert.ts` and pinned by `convert.test.ts`, so it is still English.
- **MIDI import notes.** The sentences under the part list come from `src/interchange/midi-import.ts` (`summary.notes`) and are pinned by `midi-import.test.ts`; still English.
- **Command palette contents.** Command titles, hints and errors come from `src/editor/command-palette.ts`, which is outside this sweep. The palette dialog chrome is translated.
- **Errors raised below the UI.** Controller and project errors (for example the finalized error a mocked or native edit throws) and the validators in `practice.ts` are programmer-facing or pass through from Rust; they are not translated here. The thrown backing errors in `App.tsx` and `BackingWaveform.tsx` are translated when thrown and do not follow a later language switch.
- **Key chords.** Chords made of key names (`Ctrl/Cmd + N / O`, `Backspace, Shift + Delete, …`, `Home / End, …`) stay as written, as on keycaps. `keys.note_move` and `keys.accidental` translate only the connecting words; the German ones use Strg.
- **Short labels** such as `M3 · 1` on waveform grid buttons are abbreviations and unchanged.
- **Cabinet notices** still insert an English camelCase model name and do not follow a later language switch (from sweep 3).
- **Guard reach.** The mount guard checks default states; `source-literals.test.ts` does not see single capitalised words in plain string literals, which the `fixed` list and review must catch.
- **No native speaker reviewed `et` or `de`.** Wording follows existing catalog terms and the review's corrections only.
- **Desktop drivers were not run** (they need port 9223 and the desktop test build). They were not set to a fixed UI language, so a driver run on an Estonian or German Windows may now fail in more places.
