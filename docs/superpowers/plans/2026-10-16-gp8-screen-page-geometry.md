# Live score page geometry Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Supply tested whole-system pagination, placement, inverse hits and fit arithmetic for the six-mode live score integration.

**Architecture:** One small production geometry module consumes copied eager SVG chunks, the current public immutable bounds and validated page data. Separate pagination from arrangement/magnification; return exact rendered musical objects to the existing projection canonicalizer. This plan implements geometry/extraction and fit arithmetic from the architectural spec; subsequent UI integration owns real events, fonts, cursors, selection, controls and actual desktop acceptance.

**Tech Stack:** TypeScript, pinned alphaTab1.8.4, Vitest, existing page geometry/score display types; no dependencies.

**Spec:** `docs/superpowers/specs/2026-10-16-gp8-score-layouts-design.md`. Probe/root disposition: `.analysis/parity/screen-pagination-probe-report.md` and `screen-pagination-probe-review-root.md`. Do not import or retain the throwaway probe as production.

## Global constraints

- Authoritative feature worktree only; root owns Git/review/joins. User authorized parallel delivery and all scoped changes without new approval. This module's paths are disjoint from the score-display-preferences producer; that producer exclusively owns Cargo.
- Own only `src/engraving/screen-pages.ts`, `src/engraving/screen-pages.test.ts` and the exact SDD report/logs assigned by root. No App/ScoreView/UI/CSS/native/dependency/export/projection/playback changes or whole tests/build/apps/browser/audio/capture.
- Keep original bounds/model/chunks immutable. Use only pinned public renderer/bounds contracts; no private layout/ID hooks, multiple APIs, source DOM movement or dependencies on ignored .analysis assets in production/tests.
- Real paper content is width/height minus corresponding margins; do not reuse PDF title/footer/reserved64px. Pack complete leading/system/trailing blocks by union of chunk/real/visual extents, keeping original chunk offset inside the union. No dropped block, fabricated border, individual-system shrink or clipping.
- Page gap is24display pixels. Paper border in later UI must be inset so it occupies no extra geometry. Manual and derived zoom percentages stay25–300 inclusive. Derived fit and arrangements are never persisted.

## Review focus

- A system's public real-bound envelope may extend11.3px beyond its chunk from top padding; do not treat it as clipping tolerance or align chunk top to bounds top (Task1).
- Multiple tracks/staves/voices and coincident noteheads must return exact objects using explicit current-lane preference; original getBeatAtPos is insufficient (Task1).
- Duplicate/missing/nonstring chunks and oversized title/system/footer blocks must reject rather than silently lose music or produce false pages (Task1).
- Fractional scaling, page gutters and responsive grid origins must share one forward/inverse map without mutating source bounds (Task1).
- Fit limits must be truthful at25/300 and manual137.5 must remain exact; unmeasured/nonfinite dimensions must not feed a resize loop (Task1).
