# Guitar Pro 8 Recovery and Session Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver W10 recovery of every valid unsaved document after an actual process crash and W11 restoration of clean-session tabs/location according to preference.

**Architecture:** Capture complete native ProjectSessions into a separate versioned recovery envelope; publish through an atomic manifest with same-epoch corruption fallback. One exclusively owned, bounded native writer backs up committed state; close/discard/shutdown use durable retirement barriers. W05 supplies live document addressing, one player and its activation fence.

**Tech Stack:** Existing React/TypeScript, alphaTab 1.8.4, Tauri/Rust 1.88, serde/serde_json, sha2 and atomic-write-file; serde's `rc` feature and narrowly justified `fs2 = "=0.4.3"` for process-released file locking.

**Spec:** [2026-10-15-gp8-recovery-session-design.md](../specs/2026-10-15-gp8-recovery-session-design.md). Read the accepted W05 spec/plan alongside this plan; implement only after W05's runtime and native acceptance are joined/reviewed.

## Global Constraints

- Native project schema **2**, alphaTab **1.8.4**, Rust **1.88**; ordinary compact saves/schema-1 migration remain compatible. No frontend ProjectView/model JSON recovery source.
- Preserve native full history/cursor/exact saved comparison, all retained assets/source bytes, stable document IDs, order, active ID and repaired per-tab views. Restore always stopped with a fresh activation ID.
- Preserve approved three columns, slate/cream/lime visual language and physical instrument artwork. No templates/recent library/broad preferences/GP8 runtime execution or baseline count rewrite.
- W05 ownership, busy/modal/export/Close All rules and audio gate→workspace order remain authoritative; Invalidate remains workspace-only atomic and never waits for recovery I/O or the audio gate.
- Checkpoint quiet period **2 seconds**, maximum pending wait **10 seconds**; **512 MiB** encoded envelope limit; one in-flight job and one latest-revision marker. Preference defaults **true**, affects clean restart only.
- One OS-held lock per app-data directory; one atomic manifest with current/optional same-epoch previous reference. Retirement writes a new epoch with previous=None before acknowledging close/discard/shutdown.
- Full-goal authorization and parallel method are already supplied. Root plus fresh independent artifact review replace additional user approval questions. No implementation by the design author.

## Review Focus

1. Save A, undo, branch B, crash: saved comparison is a distinct command vector, not a cursor into B; redo-only and saved-only asset references remain valid — Tasks1/2/8.
2. Slow old writer racing Close All/discard/clean shutdown must never publish removed tabs afterward, including corruption fallback — Tasks3/6/8.
3. Missing/changed native file, path alias collision or reused process ID must not overwrite a file or confuse restored document identity — Tasks2/6/8.
4. Large embedded backing must not be copied/decoded/serialized under the workspace/audio locks, nor queue snapshots per edit — Tasks1/3/6/8.
5. Crash recovery choice/preference off/failed shutdown write/failed window destruction must preserve the correct Running versus Clean classification — Tasks4/5/6/7/8.

### Task 3: Store worker implements exclusive publication, fallback and bounded writer

**Consumes:** Task2 codec. **Produces:** `RecoveryStore::acquire(directory:PathBuf)->Result<Self,String>` (holds fs2-locked file); `load(&self)->Result<Option<LoadedRecovery>,String>` where `LoadedRecovery{manifest:RecoveryManifest,recovery:ValidatedRecovery}`; `next_identity(&self,retire:bool)->Result<(u64,u64),String>` returns checked next epoch/generation (initial1/1), assigned to captured envelope off workspace lock; `commit(&mut self,envelope:&RecoveryEnvelope,lifecycle:SessionLifecycle,retire:bool)->Result<RecoveryStatus,String>` validates those expected counters and publishes them only on success; preference `read_preferences(&self)->Result<SessionPreferences,String>` and `write_preferences(&mut self,value:&SessionPreferences)->Result<(),String>`. Runtime owns fallback-to-default preference warnings. `CheckpointSchedule::{changed(now:Instant,revision:u64),due(now:Instant)->bool,started(revision:u64),finished(revision:u64)}` owns only timing/in-flight/latest metadata; runtime supplies capture and one worker. Retire increments epoch and drops previous; generation increments for every payload. Checked overflow fails before write.

- [ ] Write `atomic_manifest_is_only_commit_point`: fault-inject write/commit stages through private cfg(test) writer seams; after payload commit but before manifest replacement, old state loads; after manifest replacement new state loads. Truncated current falls back only to same-epoch authorized previous with issue/time; corrupt/future manifest does not scan an orphan. Keep valid old pair on unavailable destination/Windows sharing-lock error.
- [ ] Write `retired_epoch_never_falls_back_to_discarded_documents`: publish A/B, retire B, corrupt new current; fail recovery rather than resurrect B from an older epoch. Cleanup removes only unreferenced owned checkpoint names; preserve the spec's single diagnostic set by atomic copies before explicit reset and clean originals only after new Running manifest commit. Fault the diagnostic copy and assert originals/old manifest survive; unknown files are untouched.
- [ ] Write `two_processes_cannot_share_recovery_ownership`: self-spawn the integration-test executable in child modes, acquire one isolated directory, verify the second rejects, force-terminate first, then verify a fresh child acquires and loads.
