## 6. Limits
This sweep is complete for the files above and the strings they render through `t(...)`. Not covered, on purpose or not yet:
- **Batch convert report details.** The Details column text (`3 tracks, 4 bars. Saved as …`, `Cancelled before this file.`, losses, skip reasons and file errors) is composed as free-form English sentences in `src/batch/convert.ts`, outside the UI. It needs return codes plus arguments, as `BatchStatus` now has. Follow-up ticket: "Batch convert report details through i18n" (to be opened). `convert.test.ts` will need its expectations moved to the codes.
- **MIDI import notes.** The sentences under the part list come from `summary.notes` in `src/interchange/midi-import.ts`, which also composes English with variable parts. Same fix (codes plus arguments). Follow-up ticket: "MIDI import notes through i18n" (to be opened).
- **Command palette contents.** Command titles, hints and errors in `src/editor/command-palette.ts` (21 titles, 21 hints and errors such as `Type a single value after the command.`) are still English in a translated dialog. `searchCommands` matches typed words against the title, so translating them changes search and ranking and needs a design decision (translated title plus English aliases), search tests and a check of the drivers that type English commands. Deliberately left for the next i18n ticket, "Command palette titles, hints and errors through i18n" (to be opened). The dialog chrome is translated.
- **Errors raised below the UI.** Controller and project errors that a mocked or native edit throws pass through unchanged. The Practice settings messages are translated (`PracticeError` code, `practice.error_*`); only the `Invalid practice …` shape checks in `practice.ts` stay English and are never shown. The thrown backing errors in `App.tsx` and `BackingWaveform.tsx` are translated when thrown and do not follow a later language switch.
- **Key chords.** Chords made of key names (`Ctrl/Cmd + N / O`, `Backspace, Shift + Delete, …`, `Home / End, …`) stay as written, as on keycaps. Every help chord goes through a `keys.*` entry; the German ones use Strg, Umschalt, Entf and Links/Rechts, Estonian keeps the keycap names and translates only the direction words.
- **Short labels** such as `M3 · 1` on waveform grid buttons are abbreviations and unchanged.
- **Cabinet notices** still insert an English camelCase model name and do not follow a later language switch (from sweep 3).
- **Guard reach.** The mount guard checks default states. `source-literals.test.ts` reads JSX text, attributes, capitalised multi-word string literals, template literals (interpolations read as `X`) and `Error` messages; it does not see single capitalised words in plain string literals or English split across several literals, which the `fixed` list and review must catch. Changing the waveform `pointName` back to a template string makes it fail.
- **No native speaker reviewed `et` or `de`.** Wording follows existing catalog terms and the review's corrections only.
- **Desktop drivers were not run** (they need port 9223 and the desktop test build). They were not set to a fixed UI language, so a driver run on an Estonian or German Windows may now fail in more places.
