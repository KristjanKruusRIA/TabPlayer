# Original offline score library

Created on 2026-10-15. These compositions and factory templates were independently
authored by OpenAI Codex for TabPlayer at the user's direction. No copied songs,
vendor examples, or private test fixtures were used as source material.

The three original compositions are:

- **Windowline**: eight bars for guitar, bass, and drums.
- **Seven Steps, Five Echoes**: eight bars of drums alternating 7/8 and 5/8.
- **Lantern Counterpoint**: eight bars for keys and seven-string guitar.

The ten factory templates cover six-, seven-, eight-, and nine-string guitar;
four-, five-, and six-string bass; keys; drums; and band.
