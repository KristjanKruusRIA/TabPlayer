## Priority issues

1. **[P1] Show the current edit target on the score.** ArrowRight changed the inspector to Beat 2 while the green paper cursor remained at Beat 1. This makes users uncertain which note typing will change. Add a synchronized edit caret or note highlight, distinguish it from playback position, and keep it visible. Captured mismatch (local image, not in the repository); [integration](../../src/App.tsx:200). Suggested command: `$impeccable shape`.

2. **[P1] Keep Harmony's choice, preview and Apply together.** On opening, focus landed on Cancel and scrolled the dialog past its title and formula. Generating shapes produced twelve fret-array rows, separating candidates from the oversized diagram and actions. Preserve sensible initial focus after library loading; bound the preview; keep Apply visible; offer visual shape comparisons and disclose advanced formula controls. Harmony capture (local image, not in the repository); [dialog](../../src/harmony/HarmonyChordDialog.tsx). Suggested command: `$impeccable layout`.

3. **[P1] Put tuning errors beside the tuning field.** Invalid input produced a clear message with repair examples, but it appeared below other track controls, outside the viewport. Apply therefore seemed unresponsive. Show a field-associated error immediately beneath tuning and reveal it while preserving the draft. [Track panel](../../src/TrackPanel.tsx:41). Suggested command: `$impeccable harden`.

4. **[P2] Repair export selection layout.** Checkboxes sit centered above left-aligned names; piano staves lack clear nesting beneath their track. Both assessments observed this, and DOM inspection measured full-width checkbox layout boxes. Use adjacent checkbox/name rows, indent staves and group the measure range separately. Labels remain functional, so this is a scanning and confidence problem. [Export dialog](../../src/export/ExportDialog.tsx:51). Suggested command: `$impeccable polish`.

5. **[P2] Give the inspector clear task landmarks.** At 1440×900 it contains about **3,040 px of content in a 739 px panel**. Practice, page layout and harmony tools all live inside “Beat inspector”; Browse scales is under Beat text & chord. Keep everyday note/rhythm controls compact and provide clear Edit / Practice / Presentation navigation with local state preserved. Retain the approved three columns and advanced capabilities. [Inspector composition](../../src/App.tsx:204). Suggested command: `$impeccable distill`.
