3. `src/audio/kept-loop.test.ts`: Added tests for loops across repeats where an edit removes the repeat sign. Proves that:
   - When repeat removal leaves passes unambiguous (e.g. whole repeated passage from bar 0 to bar 3, loop spanning from before repeat to the second pass of bar 2, from pass 1 of bar 1 to after repeat, or spanning both passes of the repeated bars), `resolveKeptLoop` preserves the loop across the edit.
   - When removing the repeat inverts musical bar ordering (e.g. turnaround loop across the repeat boundary from bar 2 pass 0 to bar 1 pass 1) or leaves passes ambiguous (e.g. 3rd pass loop when repeat count is reduced to 2 passes), `resolveKeptLoop` returns `null` (which triggers clearing the loop and surfacing the transport notice).
