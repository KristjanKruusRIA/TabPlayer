# GP8 parity W21: help, manual and update status (2026-10-23)

GP8 gives access to its manual, help and application updates from inside the app. This slice adds an in-app help viewer, context help on F1, and an About topic that reports the installed version and update status honestly. It was implemented on branch `feat/gp8-parity`.

## Behavior
- **Opening help:**
  - F1 opens help on the topic for the part of the window that has focus. It works with nothing focused, which opens Getting started.
  - F1 does nothing while another dialog is open, such as the command palette, export, Library or ASCII import, so help never stacks on top of another dialog.
  - The toolbar's Help menu has "Help topics (F1)" and "About and updates" buttons. The command palette has "Help topics" and "About and updates" commands.
- **Context topics:**
  - the score → Editing the score;
  - the track panel → Tracks and sounds;
  - the inspector → The inspector;
  - the playback controls under the toolbar and the bottom dock → Playback and mixing;
  - the toolbar and the document tabs → Files, import and export;
  - anywhere else → Getting started.
- **The help viewer:**
  - A modal dialog, "TabPlayer help", lists eight topics: Getting started, Editing the score, Tracks and sounds, The inspector, Playback and mixing, Files import and export, Keyboard shortcuts, and About and updates.
  - The current topic is marked with `aria-current` and a highlighted background, which keeps the keyboard focus ring visible. The topic text is an article labelled by its heading.
  - Tab and Shift+Tab stay inside the dialog. Escape, Close or a click on the backdrop closes it, and focus returns to where it was, or to the score when that place is gone.
  - The header stays in view while a long topic scrolls. On narrow windows the topic list sits above the text.
- **About and updates:**
  - Shows "TabPlayer 0.2.0 for desktop." The version is the one shared by `package.json`, `tauri.conf.json` and `Cargo.toml`, which a unit test keeps equal.
  - "Check for updates" reports: "You have TabPlayer 0.2.0. This build has no update service, so it cannot check for newer versions. Install a newer build to update; your scores are not affected."
  - Nothing is downloaded or installed, and opening or closing help leaves the open scores, their edits and their undo history unchanged.

## Evidence
- **Unit** (`src/help/help.test.tsx`):
  - the version matches the native app and its crate, and the update status text;
  - the context mapping for the document tabs, toolbar, playback controls, score, track panel, inspector, dock and other areas;
  - the dialog opens on the given topic, lists every topic, switches topics, discloses the update status, traps Tab both ways and closes on Escape.
- **Command palette** (`src/editor/command-palette.test.ts`): the help and about commands are listed and resolved.
- **Desktop:** `tests/desktop/parity-help.mjs` on a Windows desktop-test build:
  - with a palette `fret 7` edit pending, F1 with nothing focused opens Getting started;
  - F1 from the score opens Editing the score, with its text about the command palette;
  - About and updates → Check for updates shows the exact status with the version read from `tauri.conf.json`;
  - Escape returns focus to the score, and the edit, dirty state, undo and tab count are unchanged;
  - Help menu → About and updates shows the version, and closing it leaves focus in the window;
  - no page errors.
  - `parity-command-palette.mjs` and `parity-ascii-import.mjs` still pass on the same build.
- **Verification:**
  - full `vitest`: 3,411 tests. The load-sensitive `tuning-ui`, `WorkspaceApp`, `corpus` and `library/content` files pass when run alone;
  - `tsc`.
- **Review:** an adversarial review found nine problems, all fixed:
  - the help placed the playback controls in the bottom dock, and F1 on them opened Getting started;
  - F1 did nothing with nothing focused, although the help said it worked at any time;
  - capo was described under Selected instrument, but it is in the inspector's Edit task;
  - the inspector topic said no field applies at once, and named the default zoom as the live zoom;
  - F1 could open help over another open modal;
  - the current-topic outline hid the keyboard focus ring;
  - `aria-current="page"` was used for in-place topics, and the article duplicated its heading as a label;
  - the whole `package.json` was bundled for its version;
  - a CSS comment described the wrong block, the Close button could scroll out of view, and the Help-menu focus return was untested.

  The fixes were checked by the tests above, not by a second review.

## Limits
- W21 is partial:
  - there is no update service: the app cannot check for, download or install updates;
  - help is a short in-app guide, not GP8's full manual, and is English only;
  - there is no search inside help and no links from help into the app;
  - checking for updates twice in a row does not re-announce the same status to screen readers;
  - no original-GP8 comparison.
